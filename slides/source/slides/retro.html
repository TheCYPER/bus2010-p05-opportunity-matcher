Team 5, P05 Opportunity Matcher

14

Our retrospective, honestly. What worked: when we compared our individual research, we had arrived at the same design, and planting problems in the data before coding made testing concrete. What did not: Sprint 0 produced a lot of documents and no running software, because everyone wrote in parallel and nothing brought the work together. So we change three things, each with an owner: a task is only done when it runs in the prototype; we build the thinnest end-to-end path first, then features; and every task gets a named reviewer. We will check these at the next retrospective.
