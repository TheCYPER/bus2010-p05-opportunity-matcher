Before writing any code, we broke our own demo data in eight ways: a missing end date, a skill nobody verified, a skill typed in the student’s own words, a job with no requirements, a closed job, an outdated version of a job, a profile that changed after a result was saved, and a remote-only student facing an on-site job. Each one has a named test. The grid shows every demo student against every job. We also check that every reason is traceable and that nothing unknown is ever shown as “can apply”. To be clear about what this proves: the logic works as designed on demo data. It is not a claim about real hiring accuracy, which our brief explicitly forbids.
